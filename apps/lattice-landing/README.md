# Lattice Landing

Standalone public website for Lattice.

## Local development

```bash
npm install
npm run dev
```

## Deploying separately

Set the deployment root to `apps/lattice-landing`.

Optional environment variables:

```bash
NEXT_PUBLIC_OGUN_DEMO_URL=http://localhost:3000/admin/ogun-education
NEXT_PUBLIC_WORKER_DEMO_URL=http://localhost:3000/verify/demo
NEXT_PUBLIC_API_DOCS_URL=https://lattice-be.onrender.com/docs
NEXT_PUBLIC_GITHUB_URL=https://github.com/Sadiq-Teslim/lattice-be
```
